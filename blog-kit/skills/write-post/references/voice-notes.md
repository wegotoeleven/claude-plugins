# Voice notes for blog.wegotoeleven.xyz

Snapshot from reading the existing posts. This drifts over time (the
technical posts span 2015-2022, the travel posts are all 2011) so always
cross-check against the 2-3 most recently published posts in the target
category before trusting this file over what's actually there.

## Technical posts

- Opens with a concrete, specific scenario, often admitting something
  personal or slightly self-deprecating before getting into it, e.g.
  "I absolutely cannot stand writing documentation. Well, that's kind of
  a lie..." or "I had a user with an issue recently where...".
- Explains *why* something matters before diving into *how*, and
  occasionally pivots with a direct rhetorical question ("So how cool
  would it be to leverage this when writing printed documentation?").
- Plain-language explanations for anything niche — never assumes the
  reader already knows the acronym or tool just because the author does.
  This matches how the author writes generally, not just on the blog.
- Bullet lists for enumerating symptoms, context, or examples rather than
  folding them into prose.
- Code fences for anything command-line, often with `${placeholder}`
  style variables in example commands, and inline code for
  filenames/paths/flags.
- Blockquotes when quoting external docs directly.
- Closes with a short, practical, direct sentence — a call to action or a
  one-line takeaway, not a summary paragraph.
- First person throughout. Dry, understated humour rather than jokes that
  call attention to themselves. Not sweary, not try-hard-casual.
- Contractions used freely ("doesn't", "it's", "I'm").

## Travel posts (2011 trip diary)

Distinctly different register from the technical posts — much rowdier,
written as day-to-day dispatches to friends/family rather than a
technical audience:

- Short punchy sentences mixed with longer breathless run-ons.
- Present-tense immediacy even when narrating something that already
  happened. Exclamation marks and ALL CAPS for emphasis ("AMAZING",
  "LUCKILY, HA").
- British slang throughout ("bruv", "well nice", "knackered", "skint",
  "posse").
- Self-aware, slightly absurdist humour about the author's own behaviour.
- Occasional swearing, used for emphasis rather than casually throughout.
- Ends abruptly rather than with a neat wrap-up line — these read like
  someone dashing off a quick update, not composing an essay.

## Which voice to use

If the new post is technical, use the technical voice. If it's a
personal/narrative post, use the travel voice as the closer analogue —
but check with the user first if it's not obvious which register they
want, since the two are very different and guessing wrong produces
something that doesn't sound like them at all.
